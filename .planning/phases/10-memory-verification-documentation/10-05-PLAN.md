   ```markdown
   - **Corners:** rounded-none (sharp, per host design)
   ```

   ```markdown
   ## Color Semantics Correction
   
   **v1.0 Design Error:** Compass incorrectly used emerald as a "primary" color.
   **v1.1 Correction:** Emerald is the semantic "success" color only.
   
   **Correct semantic palette:**
   - **Emerald (success):** Found mode, healthy status, confirmed items
   - **Red (error):** Revive mode, stalled status, errors
   - **Yellow (warning):** Pending items, warnings, reposition needed
   - **Blue (info):** Assess mode, informational states
   - **Neutral (gray):** Unimplemented, unknown, muted states
   
   **Why:** Paperclip host uses neutral gray as primary (text foreground, backgrounds).
   Emerald and other colors are reserved for semantic state indication only.
   This ensures visual consistency with host and reduces color overload in UI.
   ```
