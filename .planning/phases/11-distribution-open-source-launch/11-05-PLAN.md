<task type="auto">
  <name>Task 3: Verify package.json#paperclipPlugin paths are correct</name>
  <files></files>
  <action>
Extract and inspect the package.json from the npm pack artifact to confirm paperclipPlugin metadata is correct:

```bash
tar -xzf paperclip-plugin-compass-*.tgz package/package.json -O | jq .paperclipPlugin
```

Expected output:
```json
{
  "manifest": "./dist/manifest.js",
  "worker": "./dist/worker.js",
  "ui": "./dist/ui"
}
```

All three paths must:
1. Start with `./dist/` (relative to package root)
2. Point to files that exist in the .tgz artifact
3. Match what plugin-manager expects per Paperclip plugin spec

If any path is wrong (e.g., `./src/manifest.js`), the plugin-manager install will fail with "manifest not found". Halt and fix before Wave 7 publish.

Also verify version field:

```bash
tar -xzf paperclip-plugin-compass-*.tgz package/package.json -O | jq .version
```

Expected: `"1.1.0"` (not `0.3.26` or any other version). If version is wrong, Wave 7 publish will use the wrong version tag.
  </action>
  <verify>
    <automated>tar -xzf paperclip-plugin-compass-*.tgz package/package.json -O | jq '.paperclipPlugin.manifest' | grep -c "dist/manifest.js"</automated>
  </verify>
  <done>package.json#paperclipPlugin paths verified: manifest, worker, ui all point to correct dist/ subdirectories. Version field is 1.1.0.</done>
</task>
