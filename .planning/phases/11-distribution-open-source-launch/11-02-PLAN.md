<task type="auto">
  <name>Task 2: Create check-externals.mjs audit script</name>
  <files>scripts/check-externals.mjs</files>
  <action>
Create `scripts/check-externals.mjs` audit script modeled on `scripts/check-react-shim.mjs`. This script runs post-build to verify that React, react-dom, react/jsx-runtime, and zod are NOT bundled into dist/ui/index.js (per D-11).

Pattern:
1. Read dist/ui/index.js as text
2. Define forbidden imports: `react`, `react-dom`, `react/jsx-runtime`, `zod`
3. Grep for each forbidden import in the built bundle (case-sensitive, avoid matching comments)
4. Collect violations
5. If any found, log details and exit 1
6. Otherwise, log "externals guard: OK (0 violations)" and exit 0

Exact regex pattern: Look for lines containing `from ['"]` followed by the forbidden import name. The goal is to catch actual imports, not comments. Use a simple regex that avoids false positives in string literals.

Reference the keepachangelog-style comment at the top explaining why: Host provides these APIs via bare-specifier shims; bundling creates duplicate instances and breaks hooks.
  </action>
  <verify>
    <automated>test -f scripts/check-externals.mjs && grep -c "react" scripts/check-externals.mjs</automated>
  </verify>
  <done>scripts/check-externals.mjs created with forbidden imports list and violation reporting. Ready to wire into npm run verify.</done>
</task>
