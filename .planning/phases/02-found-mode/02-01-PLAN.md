**1. `src/found/derive.ts` — Derive slots from interview answers**

Export these pure functions (signatures from PATTERNS.md lines 75–86):

- `derivePrinciples(answers: InterviewAnswers): string`
  - Input: answers from vision-and-identity section (voice, values, red-lines)
  - Output: 3-5 bullet-pointed principles as markdown list
  - Logic: aggregate voice + cultural values into concrete principles
  - Example output: "- X-first culture\n- High-ownership mandate\n- Ruthless on roadmap"

- `derive12MonthGoal(answers: InterviewAnswers): string`
  - Input: answers from revenue-and-customers and growth sections (revenue target, customer count, growth rate)
  - Output: single sentence, time-bound 12-month goal
  - Example: "Reach $500K ARR with 200 paying customers by Q4 2026"

- `deriveSuccessCriteria(answers: InterviewAnswers): string`
  - Input: answers from big-picture and revenue-and-customers (long-term vision, revenue, market)
  - Output: 2-3 concrete, measurable success criteria
  - Example: "- $5M ARR\n- 10K active users\n- Top 3 in category"

- `deriveAmendmentProtocol(answers?: InterviewAnswers): string`
  - Input: optional answers (may be empty)
  - Output: standard Amendment Protocol text per vision-quest
  - For v1, return fixed text; D-05 allows placeholder text if founder hasn't specified custom protocol
  - Example: "Default: NO. Changes require dated changelog entry. Founder approves amendments; CEO can request review."

  - Input: answers from ceo-autonomy and vision-and-identity (autonomy scope, principles)
  - Output: 2-3 sentence description of how the company makes decisions
  - Example: "Founder has full autonomy on strategic direction. CEO decides on product priorities within founder mandate..."

All functions:
- Take InterviewAnswers as input, return string
- No error handling (caller validates completeness in quality-check.ts)
- No null checks (assume answers are present)
- Return non-empty strings (empty answers → empty derivation, not null)

**2. `src/found/template-fill.ts` — Fill VISION template with answers + derived slots**

Export:
- `fillVisionTemplate(answers: InterviewAnswers): FilledVision`

Logic (from PATTERNS.md lines 113–136):
1. Import VISION_TEMPLATE via esbuild `?raw` query:
   ```typescript
   import VISION_TEMPLATE from "../content/vision-template.md?raw";
   ```
2. Build slots object by combining:
   - Direct answers from interview (mission, target_customer, revenue_model, etc.)
   - Derived slots (principles, goal_12mo, success_criteria, amendment_protocol, operating_philosophy)
3. Replace all `{{slot_name}}` placeholders via regex:
   ```typescript
   Object.entries(slots).forEach(([key, value]) => {
     body = body.replace(new RegExp(`{{${key}}}`, "g"), value || "");
   });
   ```
4. Detect remaining `{{...}}` placeholders (unfilled slots):
   ```typescript
   const emptyMatches = body.match(/{{(\w+)}}/g) || [];
   const slotsEmpty = emptyMatches.map(m => m.replace(/[{}]/g, ""));
   ```
5. Return FilledVision:
   - `body`: final rendered markdown (some slots may still be empty)
   - `slotsUsed`: keys from the slots object
   - `slotsEmpty`: list of unresolved `{{...}}` placeholders

No validation here — just template rendering. Validation is in quality-check.ts.

**3. `src/found/quality-check.ts` — Validate required slots are filled**

Export:
- `checkVisionQuality(vision: FilledVision): QualityCheckResult`

Logic (from PATTERNS.md lines 160–180):
1. Define required slots (per FOUND-12, D-08):
   - `mission` — non-empty, >20 chars
   - `mandate` (CEO mandate) — non-empty, >20 chars
   - `voice` — non-empty, >50 chars
   - `principles` — contains ≥3 bullet items
   - `success_criteria` — non-empty, ≥2 criteria

2. For each required slot:
   - Check if slot is in vision.slotsEmpty (if yes, it's missing)
   - OR check if slot appears in vision.body but is empty/too short
   - Accumulate missing slots

3. Detect lingering `{{...}}` placeholders:
   - If body contains `{{`, add error: "VISION.md contains unresolved placeholders"

4. Return QualityCheckResult:
   - `isValid`: true if no errors
   - `missingRequiredSlots`: required slots that are empty
   - `emptyOptionalSlots`: optional slots (e.g., amendments, footnotes) that are empty
   - `errors`: specific error messages

Per D-08: block Apply if isValid === false. Show errors to founder.
