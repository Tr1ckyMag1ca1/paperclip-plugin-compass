# Phase 1 — UI Design Contract

> Visual and interaction contract for diagnostic dashboard plugin. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (uses Plugin SDK base components + Lucide icons) |
| Icon library | Lucide Icons (lucide-react) |
| Font | System default (inherited from Paperclip host) |

**Rationale:** Phase 1 is a minimal read-only dashboard. Plugin inherits Paperclip host's React 19, design tokens, and typography. No custom CSS framework or shadcn needed. Lucide icons bundled (~50KB gzipped, production-proven in file-viewer v0.4.0).

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, header gaps |
| xl | 32px | Layout gaps, modal margins |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (not used in Phase 1 sidebar) |

**Exceptions:** None. All Phase 1 UI elements use the 4px base scale.

**Enforcement:** esbuild bundler enforces CSS class naming (Tailwind utility approach via host design tokens).

## Typography

Phase 1 inherits Paperclip host typography via `@paperclipai/plugin-sdk/ui` design tokens.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Inventory labels, agent card text |
| Label | 12px | 600 | 1.4 | Section headers, status badges |
| Heading | 16px | 600 | 1.2 | Mode banner title, card headings |
| Display | 20px | 600 | 1.1 | Not used in Phase 1 (reserved for future modes) |

**Rationale:** 
- Body 14px at 1.5 line-height matches Paperclip's standard body text for readability in sidebar context.
- Label 12px bold for compact affordances (section headers, badges).
- Heading 16px for visual hierarchy without bloat in constrained sidebar space.

**Source:** Locked decision D-03 (mode banner at top, collapsible sections below). Inherited from Plugin SDK contract.

## Color

Phase 1 inherits Paperclip host color palette via design tokens. No custom color tokens declared.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Host surface color | Mode banner background, panel background |
| Secondary (30%) | Host card color | Agent cards, document list rows, collapsible section backgrounds |
| Accent (10%) | Host accent color | Mode override dropdown focus, refresh button accent |
| Destructive | Not used | Phase 1 is read-only; no destructive actions |

**Accent reserved for:**
- Mode override dropdown focus state
- Manual refresh button (icon or text accent)
- Status badge highlights (e.g., "VISION found" → green accent)

**Rationale:** Read-only dashboard; color role is strictly informational. No CTAs, no destructive reds, no modal overlays. Accent used only to signal interactive elements (dropdowns, refresh) and positive status states.

**Source:** Locked decision D-03 (mode banner + collapsible sections). No custom palette needed; host design tokens suffice.


### Interaction Patterns

1. **Mode Banner (Top-Fixed)**
   - Displays auto-detected mode in founder-readable language (e.g., "Assess mode — your company is healthy. Compass can audit drift since the last review.")
   - Override dropdown below: "Override mode" + 4 options: "Run a fresh audit" / "Get unstuck" / "Pivot strategy" / "Found a new company"
   - D-03 specifies mode label by what it does, not what it is
   - On dropdown change → store override in Plugin SDK worker-state (D-09) → persist across reloads

2. **Collapsible Sections (Inventory Display)**
   - Each section has a header (Label weight 600, 12px) with expand/collapse toggle
   - Default state: all sections expanded on first load
   - State: persisted in component local state (no persistence requirement in M1)
   - Sections (per D-03, INV-04):
     - **Agents**: Count badge, list of agent cards with name, role, status, last heartbeat
     - **Documents**: List of key documents (VISION.md, BOOTSTRAP.md, etc.) with presence indicators
     - **Recent Activity**: Count badge, list of recent issues (last 30 days) with date, status
     - **VISION Status**: Summary of VISION.md presence, last amendment date, section completeness

3. **Manual Refresh Button**
   - Text label: "Refresh" (sm padding, accent icon or text)
   - Located above chat input for founder discovery
   - On click → trigger inventory snapshot re-fetch via Plugin SDK (D-04)
   - Loading state: button disabled, spinner or text "Refreshing..." for 1-2 seconds max

4. **Chat Input Shell (Bottom)**
   - Text input field: placeholder "e.g., assess this company, help me revive..."
   - Send button: primary CTA, accent color, icon or text label "Send" / "Route"
   - On submit: route text to correct mode via lightweight keyword classifier (MODE-04)
   - **M1 constraint:** No response generated in M1; modes own response handling in M2-M5
   - Keyword classifier (D-07, MODE-04): regex patterns match "assess" → Assess mode, "revive"/"unstuck" → Revive, "pivot"/"reposition" → Reposition, "found"/"new" → Found; fallback to auto-detected mode

### Schema Validation Error State (D-08)

If Paperclip schema validation fails on plugin load:

```
┌─────────────────────────────────────────┐
│ ⚠ Schema Incompatible                   │
│                                         │
│ Compass requires Paperclip SDK v1.0.0+  │
│ You have: v0.x.x                        │
│                                         │
│ What to do:                             │
│ 1. Update Paperclip: `paperclip update` │
│ 2. Reinstall Compass plugin             │
│                                         │
│ [Dismiss button]                        │
└─────────────────────────────────────────┘
```

- Error text: 12–14px body weight
- Error icon: Alert triangle (Lucide `AlertTriangle`)
- No stack traces; founder-readable only
- Error displayed as modal or inline error boundary fill

## Phase 1 Visual Scope

**What ships in Phase 1:**
1. Sidebar entry "Compass" with compass icon (static, unchanging in M2-M6)
2. Main panel with mode banner + inventory display + chat input shell (no responses in M1)
3. Manual refresh button (founder triggers re-fetch of inventory)
4. Schema validation error display (founder-readable, fail-safe)
5. Mode override dropdown (persisted in Plugin SDK worker-state, survives reloads)

**What does NOT ship in Phase 1:**
- Chat response handling (modes in M2-M5 own this)
- Engagement history tab (M6)
- Approval gates or confirmation modals (M2+)
- Drift report visualization (M3)
- Settings or preferences panel (future)

**Visual consistency rule:** All Phase 1 UI elements inherit Paperclip host design language. No custom CSS framework, no shadcn presets. Lucide icons as the only external bundled asset (~50KB gzipped).
