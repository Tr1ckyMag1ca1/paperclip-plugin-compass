## Spacing Scale

**Source:** Tailwind v4 default + host token baseline (inherited from Phase 7).  
**Scale basis:** 4px unit (multiples of 4).

| Token | Value | Usage | Migration from |
|-------|-------|-------|-----------------|
| 1 | 4px | Icon gaps, tight inline padding | gap-xs → gap-1 |
| 2 | 8px | Compact element spacing | gap-sm → gap-2 |
| 3 | 12px | Intermediate spacing | gap-md → gap-3 |
| 4 | 16px | Default element spacing (body padding, card padding) | — |
| 6 | 24px | Section padding, major gaps | — |
| 8 | 32px | Layout gaps, panel sections | — |

**Exceptions (from Phase 7, carry forward):**

- **Icon touch targets:** 16px fixed (CSS pixels), not scaled
- **Modal/popover padding:** `px-4 py-3` for compact modal dialogs (16px horizontal, 12px vertical)
- **Card internal padding variants:** `padding="sm"` → `p-2` (8px), `padding="md"` → `p-4` (16px), `padding="lg"` → `p-6` (24px)

**Phase 8 Specific Exceptions:**

- **ConfidenceBar track height:** 8px `h-2` (fixed, not scaled)
- **SectionNavRail tab padding:** `px-3 py-2` (12px horizontal, 8px vertical) for compact horizontal strip
- **AmendmentDiff details padding:** `p-3` (12px) for compact code block

| Token | Color | Semantic Meaning | Phase 8 Usage | Hex (light) |
|-------|-------|------------------|---------------|------------|

| `text-blue-500` | Blue | Info, assess, audit | ConfidenceBar neutral/medium fill (optional, use emerald for >0.75, yellow for 0.4–0.75) | `#3b82f6` |
| `bg-blue-500/10` | Blue opacity | Info background | (Reserved; not used in Phase 8) | `rgba(59, 130, 246, 0.1)` |
| `text-red-500` | Red | Error, revive, stalled | DriftItemCard high severity text, AmendmentDiff remove lines, ApplyErrorDisplay | `#ef4444` |
| `bg-red-500/10` | Red opacity | Error background | DriftItemCard high severity bg, AmendmentDiff remove line background, ApplyErrorDisplay border/bg | `rgba(239, 68, 68, 0.1)` |
| `text-red-500/30` | Red opacity (subtle) | Subtle error | ApplyErrorDisplay border (30% opacity for understate) | `rgba(239, 68, 68, 0.3)` |
| `text-yellow-500` | Yellow | Warning, pending | DriftItemCard medium severity text, ConfidenceBar medium confidence fill | `#eab308` |
| `bg-yellow-500/10` | Yellow opacity | Warning background | DriftItemCard medium severity bg | `rgba(234, 179, 8, 0.1)` |

**Opacity modifiers (verified OKLCH in Phase 7):**  
- `/10` (10% opacity): Background tints, low-contrast highlights
- `/20` (20% opacity): Slightly stronger tints (e.g., `border-emerald-500/20` in chips)
- `/30` (30% opacity): Stronger tints (e.g., error borders in alert regions)

**Accent reserved for (explicit list, from Phase 7 + Phase 8):**

1. **ModeBanner left border / icon color** (per mode: emerald/blue/red/yellow) — Phase 7 D-04
2. **StatusBadge background/text** (per status: emerald=healthy, red=stalled, muted=unknown) — Phase 7 D-06
3. **DriftItemCard severity indicator** (text color + subtle bg tint per low/medium/high) — Phase 8 D-01
4. **AmendmentDiff highlight** (text + subtle bg for add/remove/context lines) — Phase 8 D-04
5. **EvidenceChip badge** (reuses StatusBadge variant) — Phase 8 D-07
6. **ConfidenceBar fill** (threshold-driven color: high=emerald, medium=yellow, low=red) — Phase 8 D-08
7. **ApplyProgress step indicator** (done=emerald CheckCircle, active=neutral foreground, pending=muted) — Phase 8 D-15
8. **ApplyErrorDisplay alert** (text-red-600 + bg-red-500/10 border-red-500/30) — Phase 8 D-16
9. **Tab navigation active state** — SectionNavRail active = `bg-foreground text-background` (neutral bold, NOT emerald) — Phase 8 D-13

**NOT for:** Primary buttons, links, interactive elements (except those explicitly listed above). All interactive elements default to neutral unless semantic.

## Component Primitives & Migration Patterns

### Phase 7 Primitives (Consumed by Phase 8)

**Card Primitive** (`src/ui/primitives/Card.tsx`)
```
variant="default"  → bg-card border-border (general containers)
variant="muted"    → bg-muted border-border (secondary surfaces)
variant="elevated"  → bg-card border-border shadow-sm (emphasized containers, modals)
padding="sm"       → p-2 (8px)
padding="md"       → p-4 (16px, default)
padding="lg"       → p-6 (24px)
Always: rounded-none (sharp corners)
```

**SectionHeader Primitive** (`src/ui/primitives/SectionHeader.tsx`)
```
title (required)   → text-base font-semibold text-foreground
subtitle (optional) → text-sm text-muted-foreground
icon (optional)    → h-4 w-4 text-muted-foreground (lucide)
actions (optional) → right-aligned React nodes (buttons, dropdowns)
Layout: flex items-start justify-between gap-4 (no padding from primitive)
```

**StatusBadge** (`src/ui/components/StatusBadge.tsx`, Phase 7 migrated)
```
status="healthy"  → bg-emerald-500/10 text-emerald-500 border-emerald-500/20 + Check icon
status="stalled"  → bg-red-500/10 text-red-500 border-red-500/20 + X icon
status="unknown"  → bg-muted text-muted-foreground border-border (no icon)
Always: text-xs font-medium, px-2 py-1, rounded-none
```

### Dynamic Color Maps (Phase 8 Pattern)

**Per Phase 8 D-02 & D-08:** Explicit static records with full class strings. Tailwind JIT-safe, no safelist config needed.

**DriftItemCard severity map:**
```typescript
const SEVERITY_CLASSES: Record<"low" | "medium" | "high", string> = {
  low: "text-muted-foreground",
  medium: "text-yellow-600 bg-yellow-500/10",
  high: "text-red-600 bg-red-500/10"
};
```

**ConfidenceBar fill threshold map:**
```typescript
const CONFIDENCE_FILL_CLASSES = {
  high: "bg-emerald-500",     // confidence > 0.75
  medium: "bg-yellow-500",    // 0.4 <= confidence <= 0.75
  low: "bg-red-500"           // confidence < 0.4
};
```

**ApplyProgress step status map:**
```typescript
const STEP_STATUS_CLASSES = {
  done: "text-emerald-500",           // CheckCircle icon
  active: "text-foreground font-semibold",
  pending: "text-muted-foreground"
};
```

### DriftReportPanel + DriftItemCard

**DriftReportPanel container:** `bg-card border border-border rounded-none p-4`  
**DriftItemCard layout:** Flex row with severity indicator on left  
**Severity color application:** Per `SEVERITY_CLASSES` map above (Phase 8 D-01)

| Severity | Text Color | Background | Visual Intent |
|----------|-----------|------------|---------------|
| `low` | `text-muted-foreground` | (none) | Low priority, faint |
| `medium` | `text-yellow-600` | `bg-yellow-500/10` | Warning, needs attention |
| `high` | `text-red-600` | `bg-red-500/10` | Critical, urgent action |

**Token migration targets:**
- `gap-xs/sm/md` → `gap-1/2/3`
- `px-sm/md` → `px-2/3`
- `py-sm` → `py-2`
- `rounded` → `rounded-none`
- `border-gray-200` → `border-border`
- Remove any hardcoded color classes (no custom color map needed if only severity uses dynamic colors per Phase 8 D-03 discretion)

### EvidenceChip + ConfidenceBar

**EvidenceChip:** Reuse StatusBadge variant (Phase 8 D-07)  
Example: `<StatusBadge status="healthy" />` for strong evidence, `<StatusBadge status="unknown" />` for weak.

**ConfidenceBar:**  
- **Track:** `bg-muted rounded-none h-2` (8px fixed height)
- **Fill:** Percentage width, color per `CONFIDENCE_FILL_CLASSES` map (high=emerald, medium=yellow, low=red)
- **Label:** Right-aligned score text `text-xs text-muted-foreground` or `text-xs font-medium`
- **Container:** Flex row, gap-2, full width

**Token migration targets:**
- `gap-sm` → `gap-2`
- `text-label` → `text-xs font-medium`
- Color classes → semantic palette (no light-only utils)

**Structure** (Phase 8 D-05):  
Keep `<details>` + `<summary>` collapsible wrapper. Migration is token-only, no structural redesign.

**Token migration targets** (Phase 8 D-05):
- `gap-sm` → `gap-2`
- `p-sm` → `p-2`
- `p-md` → `p-3`
- `mt-md` → `mt-3`

- `text-accent` → `text-emerald-600` (add lines)

**Migration strategy** (Phase 8 D-10):
