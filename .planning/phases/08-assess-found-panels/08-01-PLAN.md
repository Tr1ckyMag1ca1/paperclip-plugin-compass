| Children composition → DOM structure | Children are freely composed by caller; DriftItemCard doesn't validate structure |

| T-08-01 | Tampering (CSS injection via severity class) | DriftItemCard SEVERITY_CLASSES | mitigate | Severity values are TypeScript-enforced literals ("low" | "medium" | "high"). Map lookup only, no user input in template. Classes are static at build time. |
| T-08-02 | Information Disclosure (design token values) | Host CSS variable inheritance | accept | Token values are visual only; no sensitive data in design tokens. Host manages CSS variables; plugin inherits passively. |
| T-08-03 | Tampering (drift item data exposure) | DriftItemCard content rendering | accept | Drift items come from backend; React escapes text by default. No raw HTML injection. Severity classification is backend-determined. |
