## Spacing Scale

**Source:** Tailwind v4 default + host token baseline.  
**Scale basis:** 4px unit (multiples of 4).  
**Migration note:** Replace nonexistent plugin tokens (gap-xs, px-sm, py-md) with Tailwind native scale (gap-1 = 4px, gap-2 = 8px, gap-3 = 12px, gap-4 = 16px).

| Token | Value | Usage | Migration |
|-------|-------|-------|-----------|
| 1 | 4px | Icon gaps, tight inline padding | gap-xs → gap-1 |
| 2 | 8px | Compact element spacing | gap-sm → gap-2 |
| 3 | 12px | Intermediate spacing | gap-md → gap-3 |
| 4 | 16px | Default element spacing (body padding, card padding) | — |
| 6 | 24px | Section padding, major gaps | — |
| 8 | 32px | Layout gaps, panel sections | — |
| 12 | 48px | Major section breaks | — |
| 16 | 64px | Page-level spacing | — |

**Exceptions:**

- **Icon touch targets:** SectionHeader icon at `h-4 w-4` (fixed 16px, CSS pixels).
- **Modal/popover padding:** Use `px-4 py-3` for compact modal dialogs (16px horizontal, 12px vertical).
- **Card internal padding variants:** `padding="sm"` → `p-2` (8px), `padding="md"` → `p-4` (16px), `padding="lg"` → `p-6` (24px).

**Implementation note:** All Phase 7 components inline Tailwind utility classes directly; no `cn()` helper or `clsx` wrapper required in v1. Match existing codebase pattern of template literals for conditional class composition.

## Typography

**Source:** Host Paperclip token baseline (inherits from shadcn "new-york").

| Role | Size | Weight | Line Height | Mapping | Usage |
|------|------|--------|-------------|---------|-------|
| Body | 14px | 400 | 1.5 | `text-sm` | Default text, descriptions, body copy |
| Label | 12px | 500 | 1.4 | `text-xs font-medium` | Badges, labels, tab text, UI labels |
| Heading | 16px | 600 | 1.2 | `text-base font-semibold` | Section titles, card headers, modal titles |
| Display | 20px | 700 | 1.1 | `text-xl font-bold` | Page headings (reserve for Phase 8+; not in Phase 7 scope) |

**No plugin-side `@utility` aliases:** Keep implementation as inline host class names (e.g., `className="text-base font-semibold"`), not plugin-custom utilities like `text-heading`. Host typography tokens already exist; mechanical mapping suffices.

**Line height rationale:**

- Body at 1.5: Comfortable readability for assistant guidance copy and descriptions.
- Label at 1.4: Tight but readable for small UI text.
- Heading at 1.2: Professional, hierarchical contrast with body.

4. Interactive element focus rings (host-managed)
5. **NOT for all interactive elements** — buttons, dropdowns, links stay neutral unless explicitly semantic

## Component Primitives

### Card Primitive

**API Signature:**

```typescript
interface CardProps {
  variant?: "default" | "muted" | "elevated";
  padding?: "sm" | "md" | "lg";
  children: React.ReactNode;
}

export function Card({ variant = "default", padding = "md", children }: CardProps): React.ReactElement;
```

**Behavior & Styling:**

| Variant | Background | Border | Shadow | Usage |
|---------|------------|--------|--------|-------|
| `default` | `bg-card` | `border border-border` | none | General containers, well surfaces |
| `muted` | `bg-muted` | `border border-border` | none | Disabled states, secondary surfaces |
| `elevated` | `bg-card` | `border border-border` | `shadow-sm` | Emphasized containers, modal dialogs |

| Padding | CSS | Applies to |
|---------|-----|-----------|
| `sm` | `p-2` | 8px all sides |
| `md` | `p-4` | 16px all sides (default) |
| `lg` | `p-6` | 24px all sides |

**Corners:** Always `rounded-none` (host uses sharp corners, `--radius-lg: 0px`).

**Children composition:** Fully open — Card accepts any JSX children; no enforced slot structure. Callers compose internal layout freely (text, buttons, nested components). SectionHeader is the standardized pairing for card titles.

**Example:**

```tsx
<Card variant="default" padding="md">
  <div>Content here</div>
</Card>
```

**Location:** `src/ui/primitives/Card.tsx` (new)

### SectionHeader Primitive

**API Signature:**

```typescript
interface SectionHeaderProps {
  title: string;
  subtitle?: string;
  icon?: React.ComponentType<{ className?: string }>;
  actions?: React.ReactNode;
}

export function SectionHeader({
  title,
  subtitle,
  icon: Icon,
  actions,
}: SectionHeaderProps): React.ReactElement;
```

**Behavior & Styling:**

| Part | CSS Classes | Content |
|------|-------------|---------|
| **Icon slot (left)** | `h-4 w-4 text-muted-foreground` | Optional lucide icon, always gray; left-aligned |
| **Title** | `text-base font-semibold text-foreground` | Required, bold section heading |
| **Subtitle** | `text-sm text-muted-foreground block mt-1` | Optional, gray secondary text below title |
| **Actions slot (right)** | `flex justify-end items-center gap-2` | Optional right-aligned React nodes (buttons, dropdowns) |
| **Container** | `flex items-start justify-between gap-4` | Flexbox layout, full-width, no padding (parent supplies) |

**Layout pattern:**

```
[Icon] Title          [Actions]
       Subtitle?
```

**Example:**

```tsx
<SectionHeader
  icon={Settings}
  title="Company Agents"
  subtitle="4 active, 2 paused"
  actions={<button>Edit</button>}
/>
```

**Location:** `src/ui/primitives/SectionHeader.tsx` (new)
