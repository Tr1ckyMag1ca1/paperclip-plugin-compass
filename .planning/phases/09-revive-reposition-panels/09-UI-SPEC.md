## Spacing Scale

**Source:** Tailwind v4 default + host token baseline (inherited from Phase 7–8).  
**Scale basis:** 4px unit (multiples of 4).

| Token | Value | Usage | Migration from |
|-------|-------|-------|-----------------|
| 1 | 4px | Icon gaps, tight inline padding | gap-xs → gap-1 |
| 2 | 8px | Compact element spacing | gap-sm → gap-2 |
| 3 | 12px | Intermediate spacing | gap-md → gap-3 |
| 4 | 16px | Default element spacing (body padding, card padding) | — |
| 6 | 24px | Section padding, major gaps | — |
| 8 | 32px | Layout gaps, panel sections | — |

**Exceptions (inherited from Phase 7–8):**

- **Icon touch targets:** 16px fixed (CSS pixels), not scaled
- **Modal/popover padding:** `px-4 py-3` for compact modal dialogs (16px horizontal, 12px vertical)
- **Card internal padding variants:** `padding="sm"` → `p-2` (8px), `padding="md"` → `p-4` (16px), `padding="lg"` → `p-6` (24px)

**Phase 9 Specific Exceptions:**

- **PriorityBadge:** `px-2 py-1` (8px horizontal, 4px vertical) for tight badge sizing
- **StallSummaryBadge:** `px-3 py-2` (12px horizontal, 8px vertical) for slightly larger badge
- **ActionItemCard internal spacing:** `gap-3` for action content flex layout, `p-3` for card padding

## Known Pitfalls & Anti-Patterns (Carry from Phase 8)

### Pitfall 1: Forgetting `rounded-none` on Modals

**What goes wrong:** ActionConfirmationModal has `rounded-lg` (copy-paste from v1.0 template). Renders with rounded corners in light mode, looks broken in dark mode.

**How to avoid:** Grep all modal panel divs: `grep -r "rounded-lg\|rounded-xl" src/ui/revive src/ui/reposition`. Replace all with `rounded-none`.

### Pitfall 2: Leaving `text-heading`, `text-body`, `text-label` Without Replacement

**What goes wrong:** ActionItemCard has `<p className="text-body ...">`, but `text-body` is a v1.0 custom token. Tailwind JIT does not recognize it; text renders invisible in dark mode (black text on dark background).

**How to avoid:** Grep: `grep -r "text-heading\|text-body\|text-label" src/ui/revive src/ui/reposition`. Replace per Phase 7 D-05 map:
  - `text-heading` → `text-base font-semibold`
  - `text-body` → `text-sm`
  - `text-label` → `text-xs font-medium`

### Pitfall 3: Inline Template Literal for Priority/Severity Classes

**What goes wrong:** PriorityBadge has `className={priority === 'high' ? 'text-red-700 bg-red-50' : 'text-gray-600'}`. Tailwind JIT parser does not statically analyze ternaries; classes are not purged into CSS.

**How to avoid:** Use static const Record<Key, string> at component top per Phase 9 D-01. Full class strings in Record values, no ternaries.

### Pitfall 4: Modal Backdrop Still Using `bg-black/50`

**What goes wrong:** ActionConfirmationModal backdrop is `<div className="bg-black/50 ...">`. In dark mode text is hard to read.

**How to avoid:** Grep all modal backdrops: `grep -r "bg-black" src/ui/revive src/ui/reposition`. Replace with `bg-background/80 backdrop-blur-sm`.

### Pitfall 5: Using Forbidden React Hook (useId)

**What goes wrong:** Component imports `useId` from "react". At module load, host React shim throws SyntaxError. UI registration fails.

**How to avoid:** Run `npm run lint:shim` before commit. Forbidden list in `scripts/check-react-shim.mjs`. If ID generation needed, use Phase 7 HelpTip pattern: module-level counter + useRef (NOT `useId`).

### Anti-Patterns to Avoid

- **Do NOT use `gap-xs`, `gap-sm`, `gap-md`, `gap-lg`, `px-sm`, `px-md`, `py-sm`, `py-md`:** Use `gap-1/2/3/4` and `px-2/3/4`, `py-1/2/3/4`.
- **Do NOT use `rounded-lg`, `rounded-xl`:** Use `rounded-none`.
- **Do NOT use light-only color utilities:** `bg-green-50`, `text-slate-600`, `border-green-200` fail in dark mode. Use semantic palette.
- **Do NOT use template literals for color classes:** Unsafe in Tailwind JIT. Use static Record maps.
- **Do NOT import forbidden React hooks:** useId, useReducer, useLayoutEffect, useImperativeHandle, useDebugValue, useDeferredValue, useTransition, useSyncExternalStore, useInsertionEffect, useActionState, useOptimistic, useFormStatus.
- **Do NOT use `rounded` (bare):** Ambiguous. Use explicit `rounded-none`.
- **Do NOT leave `bg-black/50` in modals:** Use `bg-background/80 backdrop-blur-sm`.
